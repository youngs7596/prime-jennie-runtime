## 최근 작업 내역

### 1) WSL2 git ownership 이슈 영구 해소

Windows Desktop Claude Code 앱에서 WSL2 UNC 경로(`\\wsl.localhost\Ubuntu-24.04\
home\youngs75\projects\...`)의 git 리포에 접근하면 owner 불일치
(Windows `ilhsr` vs WSL `youngs75` uid 1000)로 CVE-2022-24765 보호 발동, 모든
git 명령이 `fatal: detected dubious ownership` 으로 거부되던 사건.

`git config --global --add safe.directory '*'` 와일드카드 영구 적용. 본인 머신 본인
코드 환경이라 와일드카드 보안 손실 실질 0이라 사용자 동의 후 진행. worktree 단위
개별 등록은 사용자가 worktree 자주 만들어 비효율 — 제안 금지.

### 4) Agent Teams 활성화 — Windows Desktop 앱

사용자가 docs.claude.com/ko/agent-teams 페이지를 공유. **빌트인 subagent 와는
별개의 실험 기능** 확인:

- subagent: 메인 1세션 안에서 spawn, 결과만 메인에 반환
- Agent Teams: **별도 Claude Code 인스턴스 N개**, 팀원끼리 mailbox 통신 + 공유
  작업 목록, 각자 풀 컨텍스트 윈도우 유지

사용자는 터미널 (WSL) 에서는 모든 experimental + bypass 환경변수로 풀 활성 상태.
Windows Desktop 앱은 `~/.claude/settings.json` 자체가 없어 기본값 (Agent Teams
비활성).

WSL 원본 설정 미러링하여 `C:/Users/ilhsr/.claude/settings.json` 신규 작성:

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  },
  "permissions": {
    "defaultMode": "bypassPermissions"
  },
  "effortLevel": "high",
  "skipDangerousModePermissionPrompt": true,
  "theme": "dark-daltonized",
  "teammateMode": "in-process"
}
```

WSL → Windows 미러링 시 단 한 가지 차이: `teammateMode` 를 `"tmux"` (WSL) →
`"in-process"` (Windows). 이유는 Windows 에 tmux 미설치 + docs 명시
*"VS Code 통합 터미널, Windows Terminal, Ghostty 분할 창 미지원"*. in-process 는
모든 클라이언트에서 동작.

**적용은 Desktop 앱 재시작 후**. 이 세션 종료 시점 기준 **미재시작 상태** —
다음 세션이 첫 적용. v2.1.32+ 필요해서 재시작 후 `/help` 로 버전 확인 권장.

사용자는 본인 머신에서 **Windows Claude Code Desktop 앱** (UI 선호) → WSL2

영구 적용으로 dubious ownership 에러 해소. 다음 세션이 같은 에러 보면 추가
설정 시도 말 것 — `git config --global --get-all safe.directory` 로 `*` 살아있는지
확인만.
