# DCA 영구 엔진 — 전략 A vs C 백테스트 — 2026-06-23

> 의뢰: 영석 / 지시서: 민지 / 실행: Claude Code
> 질문: DCA 영구 엔진의 기본 집행 로직으로 무조건부 균등(A)과 풀백 가속(C) 중 무엇을 채택할까.
> 답: **과거 한국 폭락 4건에서 C는 A를 이기지 못한다.** 평균적으로 살짝 지고(6개월 −0.86%p),
> MDD는 살짝 더 깊다. 이 결론은 배수·트리거를 어떻게 흔들어도 뒤집히지 않는다. 권고는 A.

이건 이번 하락과 무관한, 시스템에 영구히 남는 집행 로직 결정이다.

## 3. 무슨 일이 벌어졌나 — C의 약점은 "빠른 폭포 + 늦은 바닥"

real_history 의 C 열세(−0.86%p)는 **거의 전적으로 2020년 코로나 한 건**에서 나온다. 나머지
셋은 사실상 동률(2020-06, 2025-04)이거나 C가 이긴다(2024-08 +3.38%p). 그 한 건을 들여다보면
C의 구조적 약점이 그대로 보인다.

코로나는 트리거일(03-09)엔 −4.2%였지만 이후 2주를 더 무너졌다. C는 누적 낙폭이 커질수록
배수를 키워서:

- 03-10 DD 4.2% → 1.5배, … 03-13 DD 10% → 2배, 03-16 DD 13% → 3배
- **2020-03-16 에 2.36억을 전부 소진**(삼성 48,900원)

그런데 삼성 바닥은 닷새 뒤 **03-23 의 42,500원**이었다. C는 가장 큰 3배 슬라이스를 바닥
전에 털어 최저가를 놓쳤고(평단 51,010 vs A 47,828), 03-16에 이미 전액 노출돼 이후 −13%
추가 하락을 고스란히 맞아 MDD가 더 깊었다(−16.7% vs −11.2%). **평단·MDD 양쪽에서 손해다.**

반대로 2024-08은 폭락 당일이 곧 바닥(V자)이라, C의 선집행이 바닥을 잡아 이겼다. 2025-04도
눌림이 얕고 곧 반등해 C가 근소 우위. 결정 변수는 폭락의 깊이가 아니라 **바닥까지 걸린 시간**이다.
빠른 폭포·늦은 바닥이면 C가 진다.

자본 투입 곡선은 `results/deploy_<이벤트>.png`. 2020-03 곡선이 C가 5일 만에 2.36억을 다
깔고 멈춘 모습을, A가 10일에 걸쳐 균등하게 까는 모습과 대비해 보여준다.

## 4. 견고성 — 결론이 숫자 흔들기에 안 무너진다 (3.4절)

real_history 기준, C의 모든 변형이 A 대비 음(−)이다. C 우위로 뒤집는 변형은 없었다.

| C 변형 | 3m C−A | 6m C−A | C MDD (A −10.42%) |
|---|---|---|---|
| C 기본 | −0.91% | −0.86% | −11.05% |
| 배수 × 0.75 | −1.10% | −1.04% | −11.25% |
| 배수 × 1.5 | −0.77% | −0.66% | −10.91% |
| 트리거 = 단일일 등락 | **−0.40%** | −0.35% | −10.70% |
| R = 폭락일 종가 (3.3절 해석) | −1.29% | −1.24% | −11.41% |

읽을 점 둘. 첫째, 트리거를 "누적 낙폭" 대신 "전일 1일 등락"으로 바꾸면 열세가 가장 작아진다
(−0.40%) — 누적 낙폭 추종이 빠른 폭포에서 과하게 가속해 손해를 키운다는 뜻. 둘째, R을 3.3절
문구(폭락일 종가)로 잡으면 더 나빠진다 — 가속이 더 늦게 붙어 바닥을 더 놓친다. 그래서 본
백테스트는 5절의 R(폭락일 전일=폭락 전 기준선)을 주력으로 썼고, 그게 C에게 더 유리한 쪽이다.

## 5. 룩어헤드 차단 (4절) — 어떻게 막았는지

1. **슬라이스 크기는 전일(T−1)까지의 KOSPI 종가로만 결정.** 코드상 sizing 은 `dates[i-1]`
   까지만 참조하고 당일 `dates[i]` 종가·저가·미래값은 절대 안 본다(주석·구조로 강제).
2. **체결가 = 당일 종가.** 지불 가격일 뿐 크기 결정엔 안 쓰였으므로 인과적으로 안전.
3. **이벤트·시작일은 5절 룰로 자동 선정.** 사후에 바닥을 알고 고른 곳이 없다.
4. 검증 가능: `backtest.py` 의 `simulate()` 한 함수가 sizing/체결 분리를 담고 있어 한눈에 확인된다.

## 6. 명시 캡션 3종 (7.4절)

- **표본 수·대표성:** real_history n=4. C의 평균 열세는 사실상 코로나 1건이 끌고, 나머지 셋은
  동률 이상. 즉 "C가 확실히 나쁘다"가 아니라 "C가 A를 못 이긴다"가 정확. sim_2026 3건은
  합성·미완결(3·6개월 대부분 미도래)이라 수익 비교에서 빠짐. 2026-06은 시작 불가로 제외.
- **룩어헤드 차단:** 위 5절. sizing 은 전일까지만, 체결은 당일 종가, 이벤트는 룰 기반.
- **수수료·세금·호가 단순화:** 전부 무시. 체결가=당일 원종가. 정수주 반올림 노이즈를 없애려
  소수주를 허용(전략 비교의 순수 격리 목적). 미투입 현금은 이자 0%로 평가액에 그대로 포함.

## 7. 민지 사전 예측 채점 (8절)

예측: "C가 평단·최종수익에선 A를 이기되 MDD는 더 깊다 → 판정은 초과수익이 더 깊은 MDD를
감수할 만한가."

채점: **절반만 맞았다.** "MDD 더 깊다"는 방향은 최악 사례(코로나)에서 맞았다(real 평균도 C가
더 깊음). 하지만 **"C가 수익에서 이긴다"는 real_history 에서 성립하지 않았다** — C는 동률 내지
근소 열세다. 그래서 예측이 깐 트레이드오프("초과수익 vs MDD")의 한 축(초과수익)이 사라진다.
C는 수익을 조금 내주고, MDD를 조금 더 지고, 로직 복잡성까지 더한다. 저울에 올릴 양(+)이 없다.

## 8. 한 줄 결론과 권고

**C가 A를 이기는가? 과거 한국 폭락 4건에서 아니다 — 6개월 평균 −0.86%p, MDD는 0.6%p 더 깊고,
배수·트리거를 어떻게 흔들어도 음(−)으로 robust.** real_history 승률은 C가 3개월 수익 우위 2/4,
평단 더 쌈 3/4, MDD 더 깊음 2/4 — 어느 쪽도 C 우위가 아니다.

권고는 **무조건부 균등(A)을 영구 엔진 기본값으로** 둔다. 풀백 가속의 "쌀 때 더 산다"는 직관은,
고정 예산 + 공격적 배수가 늦은 바닥 전에 실탄을 소진시키는 실패 모드 때문에 실측에서 실현되지
않는다. A가 더 단순하고 그 실패 모드가 없다.

남는 여지 둘만 기록한다. 첫째, 만약 C를 다시 본다면 방향은 "단일일 트리거 + 더 완만한 배수 +
예산 일부 유보(깊은 단계용 실탄 비축)"다 — 조기 소진을 막는 재설계이고 이 지시서 범위 밖.
둘째, 표본 n=4는 작다. 결론은 robust 하지만 결정적이진 않다. 더 단단히 하려면 강제매도 동종
표본(연기금·환율)과 VKOSPI 적재가 필요한데, 그건 별도 게이트 입력 고도화 트랙이다.
