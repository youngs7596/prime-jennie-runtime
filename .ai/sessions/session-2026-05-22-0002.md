### 2.2 monitor balance polling 장 시간 인식 — **배포 완료** (runtime 76aa3b2)

monitor 의 KIS Gateway `/balance` poll 이 24시간 30초 고정이라 장 외 시간 낭비.
잔고의 보유수량·예수금은 체결 시에만, 평가금액·평가손익만 장중 현재가에 연동돼 변함.
- `LivePositionsPoller` 가 `MarketCalendar` 로 장 시간 판정 — 장중 30s / 장 외 300s
- heartbeat TTL 적응적 (`max(180, interval+60)`) — 장 외 느린 주기에도 미만료
- `MONITOR_IDLE_POLL_INTERVAL_SEC` env (default 300), docker-compose 등재
- 검증: `/status` `current_interval_sec=30` (정규장 확인)

### 2.3 진단 — "Monitor poll failing" 알림 (코드 변경 없음)

`monitor/poller.py` 가 `/balance` poll 3회 연속(=90s) 실패 시 critical 알림.
실제 원인 = `httpx.ConnectError` (kis-gateway TCP 불가) = 주로 **배포 시 startup
race**: 배포가 monitor·kis-gateway 를 함께 재생성하는데, kis-gateway 에 healthcheck
가 없어 monitor 가 `service_started` 까지만 대기 → gateway 앱 준비 전 poll. 양성·
자가회복(`Monitor recovered` 동반). 근본 해결 = kis-gateway healthcheck 추가.
