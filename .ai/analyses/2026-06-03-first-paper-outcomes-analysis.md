# 첫 paper 측정 데이터 분석 — 2026-06-03

paper outcomes 측정이 P2.5 복구 (5-29) 로 살아난 뒤 처음 보는 전체 분석이다. 분석 시점
기준 측정 완료 1,086건 (data_missing 287건 별도). 오늘 발견·수리한 "윈도우 미도래 시트
영구 차단" 버그로 갇혀 있던 35건은 6-4 측정 cycle 에서 재측정되므로 이 분석에 없다.

## 1. 이 데이터가 무엇을 담고 있는지 (먼저 읽을 것)

측정된 1,086건의 99% (1,077건) 는 **이미 폐기된 LLM-at-core 시기 (4-19 ~ 5-21) 의
시트**다. 결정론 코어 (5-22 전환) 이후 시트는 9건뿐이라 어떤 결론도 낼 수 없다
(n<30 단일 구간 정량을 근거로 쓰지 않는다는 원칙 그대로).

따라서 이 분석은 "지금 전략이 좋은가" 에 답하지 못한다. 답하는 것은 두 가지다.

1. 폐기된 LLM 시기가 얼마나 나빴는지의 사후 확정 — 폐기 결정 (5-22) 의 정량 근거 보강
2. 측정 인프라가 제대로 작동하는지의 검증 — 앞으로 결정론 코어를 같은 잣대로 잰다

## 2. LLM 시기 사후 확정 — 시장을 빼고 봐도 크게 나빴다

| 항목 | 값 |
|---|---|
| 측정 건수 | 1,086 |
| 평균 PnL | **-2.19%/건** |
| 승률 | 34.6% |
| 같은 보유 기간 KODEX200 평균 | **+4.48%** |
| 알파 (시트 - KODEX200) | **-6.67%p** |
| 벤치마크를 이긴 비율 | 11.6% |

측정 기간 (4월 말 ~ 5월 중순) 은 이란전쟁 급락에서 시장이 회복하던 구간이라 KODEX200 을
그냥 들고만 있어도 평균 +4.48% 가 나왔다. 그 장에서 LLM 이 고른 종목들은 평균 -2.19% 를
잃었다. 시트 10건 중 9건이 지수만 못했다.

실거래 기록과의 교차 검증: 실제 체결됐던 거래의 baseline (-2.24%/건, 승률 27%) 과 paper
전수 측정 (-2.19%/건, 34.6%) 이 거의 같다. simulator 가 현실을 잘 재현한다는 뜻이고,
동시에 실거래 손실이 "운이 나빠서" 가 아니라 선정 자체의 문제였다는 뜻이다.

5-11 주가 절대 손실로는 최악 (승률 4.7%) 이지만, 시장 자체가 빠진 주라 알파로는 -3.47%p.
오히려 시장이 강하게 오르던 4-27 ~ 5-04 주에 알파가 -8 ~ -9%p 로 가장 나빴다. 시장이
오를 때 따라가지 못하는 종목을 고르고 있었다는 뜻 — supply_demand 과대평가로 이미 오른
대형주를 추격하던 그 결함 (5-25 분석) 과 일치한다.

### 청산 사유별 — 손익 비대칭

| 사유 | n | 평균 PnL |
|---|---|---|
| fixed_sl (손절) | 416 | **-7.21%** |
| trailing_tp (추적익절) | 385 | +1.99% |

| fixed_tp (고정익절) | 20 | +7.15% |

손절 평균이 -7.21% 라는 점이 중요하다. 손절선은 3~5% 인데 평균 손실이 그 두 배다 —
**밤사이 갭하락이 손절선을 뚫고 시작하는 경우가 많았다**는 뜻이다 (v0 simulator 는
다음날 시가에서 손절을 잡는다. 이건 모델 한계가 아니라 현실이다 — 실거래도 갭은 못
막는다). 손절은 크게 (-7.2%), 익절은 작게 (+2.0%) 가 반복되면 승률 50% 라도 음의
기대값이다. 변동성 큰 종목 선정 + 추적익절의 이른 청산 조합이 만든 구조적 비대칭.

## 3. 측정 인프라 검증 — 작동한다

- 측정값이 실거래 baseline 과 일치 → simulator 신뢰 가능
- 벤치마크 (KODEX200) 비교 경로 검증 완료 → 오늘 배포한 /api/paper API 가 같은 산식
- 발행 시점 macro gate 는 전부 open (closed 면 시트가 안 나오므로) → 국면 분해는
  gate 가 아니라 시장 지표 (KOSPI 주간 등락) 기준으로 봐야 한다는 것 확인
