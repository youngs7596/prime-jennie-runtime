## 중요 참고사항

### 두 갈래 fix 의 직교성

**분모 (total_asset)** vs **macro floor (0.75)** 는 서로 독립. 어느 한쪽
fix 만으로도 sizing 은 의미있게 늘었지만 둘 다 한 PR 로 묶은 이유:
사용자 요청이 두 가지 동시 + 효과가 곱셈으로 누적되어 예상치 명확.

원래 origin 에 base_pct 상향이 이미 들어와 있던 게 우연히 잘 합쳐졌음.
세 변화의 multiplicative 효과로 종목당 슬롯이 2~3 자릿수 배율로 증가.

### v2 와의 sizing 차이 — cash floor + smart skip 미적용

v2 는 `cash_keep = total × 10%`, `smart_skip: by_cash < target × 50% → 0`
같은 보호 장치가 있었음. v3 는 일단 분모/cap/클램프만 가져옴. 33 종목
풀 보유 + 시트 발행 폭주 시 cash 가 0 으로 빨려 들어갈 위험은 cash 클램프
만으로 막혀있음 (음수는 안 됨). 하지만 "현금 0 직전까지 매수" 는 가능 →
다음 거래일 portfolio rebalancing 여유 0. 운영 데이터 보고 판단.

### MACRO_AUTO_OVERRIDE_DISABLED + 새 discretize 의 상호작용

bull market 기간 동안 `MACRO_AUTO_OVERRIDE_DISABLED=1` 로 closed 조건이
만족돼도 LLM open 판단을 유지. 거기에 새 discretize 가 open 이면 최소
0.75 강제 → **closed 조건 발동해도 매매가 0.75 size 로 진행**. 이중
공격적. 원래 안전장치 두 개가 동시에 약화된 셈. STOP 은 계속 작동하므로
사용자가 위급 시 끌 수 있지만, 자동 차단은 약함을 의식.

다음 거래일 운영 후 macro_runs 의 LLM 판단 + 실 매매 결과 보고
MACRO_AUTO_OVERRIDE_DISABLED 해제 시점 결정 권장 (bull market 끝나면).
