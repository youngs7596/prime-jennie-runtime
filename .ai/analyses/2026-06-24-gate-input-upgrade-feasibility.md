# 게이트 입력 고도화 · 전략 B 부활 — 조달 가능성 검토 (2026-06-24)

6-23 세션이 남긴 선택 트랙이다. 폐기한 전략 B(분봉 RSI + VKOSPI + 수급 확인 게이트로
급락 때 분할매수를 가속)를 되살리려면 새 입력 세 가지가 필요한데, 각각 지금 받을 수
있는지 확인했다. 결론은 둘은 만들 수 있고 하나는 영영 못 만든다 — 그 하나가 전략 B의
핵심 게이트라, 전략 B 자체는 백테스트 없이 라이브로만 돌릴 수밖에 없다.

## 전략 B가 요구하는 입력 세 가지

1. **분봉 RSI** — 장중 과매도 판정 (급락 가속의 방아쇠)
2. **VKOSPI** — 변동성 급등 확인 (공포 국면 게이트)
3. **수급 확인** — 외국인·기관(이상적으로 연기금 분리) 순매수 전환 확인

## 지금 받을 수 있는가

### 분봉 RSI — 영영 불가 (영구 블로커)

KIS 게이트웨이는 분봉을 약 2개월치만 준다. 과거로 확장이 안 된다. 분봉 RSI 를 쓰는
어떤 규칙도 과거검증을 할 수 없다. 6-23 이 전략 B 를 "구조적으로 측정 불가"로 폐기한
이유가 이것이고, 시간이 지나도 풀리지 않는다(분봉은 계속 2개월 창으로 흐른다).

### VKOSPI — 수집 안 함, 신규 필요 (가능)

코드 어디에도 VKOSPI 수집기가 없다. 운영 DB 에 변동성지수 시계열이 없다. 정식 출처는
KRX(코스피200 변동성지수)다. KRX 데이터포털에서 일별 시계열을 과거까지 받을 수 있어
신규 일별 수집기 하나면 된다. (시장데이터 단일출처인 Yahoo chart API 에 깨끗한 VKOSPI
티커가 있는지는 불확실 — KRX 가 확실한 출처다.) 일봉이라 백테스트 가능.

### 연기금 분리 수급 — 출처 교체 필요 (가능)

지금 `stock_investor_tradings` 는 네이버 frgn 페이지에서 종목별 외국인·기관·개인
순매수를 받는데, **기관이 한 덩어리**다(연기금 분리 없음). 6-23 에 "국민연금 매도가
끝났나"를 못 본 게 이 한계였다. KRX 데이터포털은 투자자 유형별 매매를 기관 안에서
연기금·금융투자·투신 등으로 쪼개 준다. KRX 출처 수집기를 새로(또는 기존 collector 에
KRX 경로 추가) 만들면 된다. 일별이라 백테스트 가능.

## 그래서 무엇을 권하나

**전략 B 통째 부활은 권하지 않는다.** 핵심 방아쇠인 분봉 RSI 를 과거검증할 수 없으니,
전략 B 는 백테스트 없이 실계좌 DCA 에 라이브로만 얹어야 한다. 6-23 백테스트가 이미
"가속(C)은 균등(A)을 못 이긴다 — 배수·트리거를 흔들어도 음(−)으로 robust"를 보였고,
전략 B 는 그보다 복잡한 가속이다. 검증 못 하는 더 복잡한 가속을 실탄에 얹는 건
6-23 결정(A 영구·가속 비활성)과 정면으로 어긋난다.

**대신 만들 값어치가 있는 건 입력 두 개를 독립 자산으로 적재하는 것이다.** VKOSPI
일별 시계열과 KRX 연기금-분리 일별 수급은 전략 B 와 무관하게 쓸모가 있다.

- 6-23 같은 "한국만의 수급 충격"을 당일 판정하는 데 연기금 분리 수급이 직접 답이다
  (지금은 기관 덩어리라 못 본다).
- 매크로 게이트의 입력으로 VKOSPI 를 더하면 게이트 품질 자체가 올라간다.
- #2(게이트 닫힘이 옳았나)의 표본이 쌓일 때 국면 변수로도 쓴다.
- 둘 다 일별이라 과거검증이 되니, 얹기 전에 값어치를 잴 수 있다.

요약하면, 분봉 RSI 블로커 때문에 전략 B 는 접어 두되, VKOSPI·연기금 수급 적재는
"게이트·수급 판정 고도화"라는 더 넓고 검증 가능한 목적으로 따로 진행하는 게 맞다.
이건 신규 수집 파이프라인 두 개를 만드는 일이라, 착수 여부는 영석님 결정이다.
