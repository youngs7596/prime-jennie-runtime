## 4. Coordinator 실태 검증

5-23 갱신 단락이 "골격 (State Hub / Decision Authority / Event Bus) 가동 중" 단언했지만 사실은 절반:

| Layer | 실태 |
|---|---|
| A. State Hub | 미구현. `HeldSheetSummary` / `DecisionContext` / `StateHub` 코드 0건 |
| B. Decision Authority | 미구현. sync query channel 없음 |
| C. Event Bus | 가동 — coordinator-listener daemon + Redis stream `coordinator:events` + `event_log` archive (migration 017). dispatcher + 2 advisory policies (`duplicate_today`, `recent_stoploss_cooldown`) — Telegram 알림만, 실제 차단은 strategy/engine 가 별개로 |

즉 사용자가 원한 "보유 종목 평가 + 방향 결정" 의 정확한 layer (A + B) 가 미구현. 5-22 결정론 코어 전환 + 후속 가드 fix 슬라이스에 시간·주의가 다 들어가면서 후순위로 밀린 흐름.
