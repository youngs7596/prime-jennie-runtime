## 1. 우선순위 전환 — silent failure 가드 → paper outcomes

직전 세션이 1번으로 남긴 가드 작업은 task 1-5 로 시작했지만, 사용자 회의가
나온 시점에서 "운영 가치를 측정할 데이터가 더 시급" 으로 판단을 바꿨다.
silent failure 가드는 task 1-5 그대로 보류 상태로 두고, paper outcomes 슬라이스
(task 6-8) 를 새로 만들어 진행. 가드 작업은 다음 commit 그룹에서 재개.

이번 우선순위 변경의 핵심 근거는 두 가지다. 첫째, KOSPI 가 5월 자체로 강한
국면이라 단순 인덱스 BUY & HOLD 가 system 의 선별을 앞서고 있고 (5-25 분석
v3 LLM 시기 -2.24%/건 27% 승률 이미 기록), 사용자가 운영 가치를 의심하는 게
데이터적으로 근거 있는 상태. 둘째, paper outcomes 가 없으면 STOP 풀고 실제
운영을 재개해야 system 의 가치를 측정할 수 있는데, 그 비용이 큼. paper
측정 인프라가 있으면 STOP 유지 상태에서도 일주일+ outcomes 가 쌓인 다음
운영 재개 여부를 정량적으로 결정 가능.

## 8. 중요 참고사항

paper outcomes v0 의 한계 — 시뮬 정확도가 1분봉 부재 종목에서 떨어진다.
overextension_exit 가 skip 되고, 일봉 4-tick 의 순서 [open, high, low, close]
가정이 같은 거래일 안 실제 가격 시퀀스와 다를 수 있다. fixed_tp 가 open
에서 매칭되면 high 까지 안 감 (test_fixed_tp_hit_on_high 가 그 동작 확인).
이 한계는 metadata 에 coverage='daily_only' 로 명시 기록 + 1분봉 어댑터 v1
에서 해소.

시트 가격 모델 — 시트 발행일 종가 entry 는 fast_loop 가 11-14시 발행 직후
진입하는 실제 흐름과 4-5 시간 갭. 시트 발행 직후 KIS 호가의 시가/매수가
와도 다르다. 절대 PnL 의 정밀도는 ±몇% 단위 오차 있다고 봐야 하고,
시트별 상대 비교 (선별 알파 측정) 는 그 오차에 영향 덜 받음. 사용자에게
"실제로 진입했다면 ±N%" 식으로 보고할 때 정밀도 한계 같이 명시.

silent failure 가드 보류 — 5-26 직전 세션이 1번으로 남긴 항목인데 이번에
paper outcomes 로 우선순위 전환. 다음 commit 그룹에서 재개해야 잊지 않음.
status='success' + 결과 테이블 0건 패턴은 아직 검출되지 않은 dead path 가
더 있을 가능성 큼.
