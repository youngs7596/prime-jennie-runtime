## 2. 라이브 검증에서 드러난 것 — 서진시스템은 이미 추적 중이었다

0001 의 "시트 만료로 tracker 밖" 가정은 틀렸다. STOP 이 청산을 막아 온 탓에
5-26 자동 발행 시트가 추적을 유지하고 있었다. 영석님이 새 명령으로 기존 추적을
취소하고 회복선 -1% 로 재등록 — 등록·조회·취소·재등록 경로가 실전 완주됐다.

이어서 두 번째 발견: **서진시스템이 -10.5% 라 /adopt 의 안전장치 손절선(-10%)
아래에 이미 있었다.** STOP 을 풀면 회복 대기가 아니라 즉시 손절될 상황. 선택지
셋 (그대로 손절 수용 / 안전장치 생략 코드 수정 / 추적 제외) 을 드렸고 영석님이
"1주, 8천원이라 괜찮다" 며 수용을 선택.

## 4. 두산밥캣 재편입

"왜 관리 밖으로 뺐냐" 질문에 — 계속 보유와 추적 유지(청산 룰 집행)는 양립
불가였다고 설명. 대신 보호도 사라졌음을 짚었고, 영석님이 재편입 지시. 취소가
시트를 지우지 않는 덕에 **5-21 원시트 (trailing +5%/-3% · 손절 -5% · 250거래일)
를 그대로 재등록**. 고점 추적은 매입가(69,077원)에서 새 출발 — 과거 고점 기준
trailing 즉시 발동 차단. 현재 -3.6%, **손절선 65,623원까지 여유 1.5%**. 영석님:
"그대로 둬, 손절되면 통지 보고 판단할게."

- **time_stop 은 "보유일수 초과 + 15:20 이후" 둘 다 필요하다** (exit_evaluator).

- Claude 가 control 명령을 직접 발행할 때의 관례: 결정은 반드시 대화에서
  사용자가 명시적으로, 발행은 텔레그램 봇과 같은 stream 으로, issued_by 에
  `claude_code:*` 를 남겨 추적 가능하게. 실행 후 체결·상태·통지 3종 검증.
- tick 평가는 구독 종목에만 돈다. 구독은 fast-loop 기동 시 positions + 최근
  30일 시트 ticker (한도 41). 재편입 종목이 positions 에 있으면 자동 커버.
- ruff 저장소 전체 check 는 여전히 main 부터 깨져 있다 (airflow.py 등,
  이번 변경과 무관).
