### 4.1 결정론 코어의 _news_score 가 dead path 만 봄

5-22 결정론 코어 전환 이후 35일째 모든 종목의 news 점수가 중립 5.0 으로
굳어 있었다. 7팩터 중 한 축이 비활성 — universe 차별화에 기여를 못 함.

원인은 `_news_score(candidate)` 가 `candidate.news_sentiment_avg` 만 보는데,
`enrich_universe` 가 옛 `news_sentiments` 테이블을 SQL 로 읽는다는 것.
news_pipeline_kor 가 2026-04-21 부터 Qwen3 메타데이터 기반으로 옮겨가면서
(`news_events` 테이블 + impact_level × event_type 분포) **옛 테이블에 새
데이터가 더 이상 안 들어왔다**. enrichment 가 빈 결과 → `news_sentiment_avg
= None` → `_news_score` 가 `V2_NEUTRAL["news"]` 반환. 모든 종목 동일.

문서상으로는 새 path 의 `RealNewsEventFeeder` 가 이미 `events_by_impact`
를 채워서 LLM 프롬프트 (context_builder) 에 넣고 있었지만, 결정론 점수
산식과는 연결돼 있지 않았다. LLM 영향은 5-22 이후 거의 없으니 사실상 news
신호가 통째로 죽어 있던 셈.

같은 세션 안에서 fix 까지 (commit `61d447c`):
- `EnrichedCandidate` 에 `news_event: NewsEventEntry | None` 추가,
  `news_sentiment_avg` 제거
- `enrich_universe` 가 `RealNewsEventFeeder` 위임 (LLM 프롬프트 path 와
  feeder 공유, 중복 SQL 없음)
- `_news_score` 산식: high pos +1.5/cap3, med pos +0.5/cap1, high risk
  -2/cap4, med risk -0.5/cap1, staleness>24h -0.5, 기사 0건 중립
- 옛 path 제거: `_load_news_sentiment` / `_sentiment_to_0_100` /
  `NEWS_LOOKBACK_DAYS`

scout / jobs / slow_loop 영역 467개 테스트 통과. push + deploy 완료.
