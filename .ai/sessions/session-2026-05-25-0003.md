# 세션 정리 — 2026-05-25-0003

이번 세션은 "오늘 휴장인데 scout 가 열심히 돌았다" 는 사용자 관찰 한 줄에서 시작해서 두 갈래 fix 와 한 번의 깊은 토론으로 끝났다. fix 는 휴장일 가드 + ETF universe 정화 두 건이고, 토론은 결정론 코어가 우량주만 추천하는 게 문제냐 아니냐는 주제였다. 결론은 우량주 쏠림은 알파의 출처라 인위적 분산은 잘못된 방향이고, 진짜 약점은 "같은 우량주 풀 안에서 지금 들어갈 한두 종목을 골라내는 능력" 이라는 것. 다음 세션의 메인 주제도 거기서 출발한다.

매매는 5-22 결정론 코어 전환 이후 진행 중. quant.py 7팩터 + MA 평활 + 히스테리시스로 종목을 고르고, conviction 평균 0.62 정도로 매 cycle 약 10 종목을 시트로 발행한다.

## 2. 이번 세션 작업

### 2.1 휴장일 가드 (commit `ae5cf32`)

오늘 5-25 휴장일에 macro 7회 + scout 7회 + position_sheets 라이브 15 시트가 발행됐다. 원인은 단순했다. cron 이 `30 8-14 * * 1-5` 처럼 평일 1-5 만 보고 한국 휴장 캘린더는 모른다. `kis_gateway/market_hours.py` 의 `MarketCalendar.is_trading_day` (KIS chk-holiday 호출) 가 이미 구현돼 있었지만 fast_loop 과 monitor 진입부에만 붙어있고 slow_loop 과 job_worker 핸들러 진입부에는 안 붙어있었다.

매매 영향은 없었다. fast_loop 의 `entry_valid_until_expired` 가드 + 사이트 schema 의 valid_until ≤ 15:30 룰 + Redis EXPIRE 가 삼중으로 차단해서 시트는 다 발행 당일 만료. 다만 같은 5-22 금요일 종가 데이터로 결정론 코어가 거의 같은 시트를 7회 반복 발행한 게 DB 오염 + LLM 비용 (macro / wsj digest 쪽) 으로 남았다.

fix 는 `infra/trading_calendar.py` 신규 헬퍼 + 5 핸들러 진입부에 한 줄씩. global_news_digest 는 한국 휴장과 무관한 글로벌 정보 (WSJ + 외신) 라 가드 제외했다. 다음 거래일 macro 가 휴장일치 글로벌 뉴스도 함께 봐야 하니까. 테스트 5/5 통과, 251 회귀 통과 (실패 1 건은 `SCOUT_PROMPT_VERSION` 스테일 테스트로 우리 변경 무관).

### 2.2 ETF/ETN/ELW universe 정화 (commit `61daf0a`, migration 021)

오늘 발행된 15 시트 중 두 건이 ETF 였다. KODEX 레버리지 (122630) + TIGER 미국필라델피아반도체나스닥 (381180). 둘 다 SECTOR_MOMENTUM 으로 분류돼 일반 종목과 같이 통과. `RealUniverseFeeder` SQL 이 `is_active AND market_cap IS NOT NULL` 만 보고 종목을 가져와서, ETF 가 시총 큰 KOSPI 종목과 한꺼번에 universe 200 안에 들어온 게 원인.

5-22 에 적용한 ETN 종목명 필터 (`NOT ILIKE '%ETN%'`) 는 KIS 일봉이 빈 응답인 ETN 만 잡았고, 정상 거래 ETF (KODEX/TIGER) 는 그대로 통과했다. 근본 해법이 필요했다.

방법은 `stock_masters` 에 `security_type` 컬럼을 추가하고 KIS `search-info` (CTPF1002R) 응답의 `scty_grp_id_cd` 를 매핑하는 것. 운영 kis-gateway 컨테이너에서 직접 호출해 spec 검증한 결과 값이 명확하게 갈렸다.

- `ST` → STOCK (보통주, 우선주 둘 다)
- `EF` → ETF
- `EN` → ETN
- `EW` → ELW

migration 021 + `kis_api.search_info` + gateway endpoint `/api/quotations/search-info/{code}` + `seed_stock_masters` 의 kis_gateway_url 인자 추가 + universe SQL 에 `AND security_type = 'STOCK'` 한 줄. 매핑 실패는 STOCK fallback (안전 측 — universe SQL 이 STOCK 만 보므로 분류 실패 종목도 포함됨).

backfill 은 job-worker 컨테이너 안에서 `seed_stock_masters` 1회 수동 실행. KIS 초당 약 20 호출 안전 마진 0.06 초 sleep 으로 약 3분에 끝났다. 결과 4026 종목 중 STOCK 2779 / ETF 874 / ELW 373 / ETN 0 (ETN 은 시총이 작아 시총 페이지에 안 잡힘 — universe filter 가 어차피 자연 배제).

부수 발견 한 가지. backfill 에서 KOSDAQ 1678 종목이 신규 INSERT 됐다. 기존 stock_masters 는 사실상 KOSPI 전용이었다 (메모리 `project_universe_etn_pollution` 의 "market 전부 KOSPI" 가 사실). 이제 KOSDAQ 대형주가 universe top-200 안에 일부 들어올 가능성이 생겼다. 5-26 이후 universe 구성 한 번 관찰할 가치가 있다.

### 2.4 우량주 쏠림 분석 → 다양성 메커니즘 폐기

5-22 이후 12 sweep 통계: 124 candidates 중 unique ticker 19 개뿐, 30 promoted 중 unique 18 개. 같은 종목 top 12 가 다 똑같이 2회씩 promoted. 7팩터 가중치 표에서 supply_demand 가 만점 대비 72% 로 가장 강하게 작동 (거래대금 큰 우량주 유리), value 가 61% (저PER/저PBR 우량주 유리). MA 평활 + 히스테리시스가 한 번 통과한 종목을 계속 통과시키는 구조.

제가 이걸 "다양성 부족 문제" 로 잡고 cooldown / sector cap / 가중치 재조정 같은 메커니즘을 제안했는데, 사용자가 결정적인 한 줄을 줬다. "my little jennie 시절부터 우량주가 좋은 성적을 냈다. 우량한 녀석을 좋은 타이밍에 들어갔을 때 재미를 많이 봤다. 필터링이 중요한 게 아니고 돈을 벌어줄 녀석을 잘 골라내는 능력이 중요하다."

분석 흐름의 방향 자체가 빗나갔던 것. 우량주 쏠림은 algorithm 의 결함이 아니라 알파의 출처. cooldown / sector cap 같은 인위적 분산은 알파를 깎는 안이라 폐기. 진짜 약점은 같은 우량주 풀 안에서 "지금 들어갈 한두 종목" 을 골라내는 변별력이다. promoted 종목들의 conviction 표준편차가 작아서 "삼성전자 0.65 vs LG전자 0.61" 같은 식으로 차이를 못 만든다. 점수 구조 자체를 손대야 하는 더 깊은 토론이라 다음 세션으로 넘겼다. ETF fix 는 universe quality 차원의 별건이라 그대로 진행했다.

## 4. 다음 단계 — 어떤 종목을 노려야 할지

다음 세션의 메인 주제. 그동안 쌓인 데이터를 여러 각도로 분석해서 prime jennie 가 노릴 종목 선별의 방향성을 잡는다.

분석 재료가 세 갈래로 나뉜다.

**v3 결정론 코어의 짧은 이력** — 5-22 이후 약 30 promoted, 18 unique. 표본이 작지만 supply_demand·value 중심 점수 구조와 우량주 쏠림 패턴이 이미 보인다. position_sheets / screening_candidates / daily_quant_scores / outcomes 를 갖춰서 factor 별 outcome 기여도를 계산할 수 있다. 다만 5-26 이후 영업일이 더 쌓여야 outcomes 가 채워진다.

**v2 (my little jennie) 의 긴 이력** — prime-jennie repo 의 trade 기록과 LLM 판단 이력. 사용자가 알파의 출처라고 명시한 시기. 어떤 종목·어떤 섹터·어떤 진입 타이밍이 실제 수익으로 이어졌는지 패턴을 뽑을 수 있다. 결정론 코어가 비슷한 패턴을 잡고 있는지 vs 놓치고 있는지 비교가 가장 강력한 단서가 될 듯하다.

**시장 데이터** — daily_prices / news_events / sector momentum / macro 이력. 같은 종목이라도 진입 시점에 따라 결과가 어떻게 갈렸는지, momentum 이나 news 의 단기 변화가 outcome 과 어떻게 상관됐는지 추적 가능.

여러 각도에서 들여다볼 만한 것들:

- 같은 우량주를 매번 추천하는 와중에, 실제로 어떤 진입 시점에 들어갔을 때 수익이 났고 언제 손실이 났는지. v2 outcomes 분포의 시간 분포로 보면 "타이밍" 의 형태가 잡힐 가능성.
- 7팩터 중 momentum / news / supply_demand 의 단기 변화 폭과 outcome 의 상관관계. 정적인 quality / value 보다 동적 팩터가 타이밍을 더 잡는지 검증.
- 섹터 강세 시기 패턴. 5-25 발행 시트 중 반도체/IT 5건이 압도적이었는데, 이게 섹터 momentum 신호가 강했던 시점인지 단순한 우량주 비중 효과인지 분리.
- conviction 의 변별력 — 우량주 풀 안에서 conviction 0.60 ~ 0.65 사이가 너무 밀집해 있다면 점수 분포를 stretch 할 방법. 또는 별도 진입 타이밍 score 를 곱하는 방향.
- v2 의 LLM 판단이 좋았던 사례와 결정론 코어가 그 종목을 어떻게 평가했을지 시뮬레이션. LLM 비결정성을 다시 들이는 게 아니라, 어떤 신호가 LLM 의 강점이었는지 알아내서 결정론 layer 에 옮길 수 있는지 보는 차원.

이 분석을 통해 잡고 싶은 방향성은 두 가지다. 첫째, 우량주 풀 안에서 "지금 들어갈 한두 종목" 을 명확히 가리는 변별력. 둘째, 진입 타이밍 신호 (현재 momentum 가중치 20 / news 10 이 충분한지) 의 재조정 또는 신규 시그널 도입 여부.

다양성 메커니즘 (cooldown, sector cap) 은 이미 폐기했으므로 후보군에 없다. 점수 가중치 재조정과 신규 시그널 도입이 주된 후보가 될 것.
