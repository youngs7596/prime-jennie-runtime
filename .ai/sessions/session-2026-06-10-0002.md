## 5. 중요 참고사항

- **잡 수동 실행 방법**: job-worker 컨테이너에 `docker exec -i ... python -` 로
  스크립트를 흘려 넣어 잡 함수를 직접 호출 (AppConfig 가 컨테이너 env 를 읽음).
  운영 컨테이너엔 scripts/ 가 없어 이 방식이 표준. 스케줄러를 안 거치므로
  scheduled_job_runs 에 기록이 안 남는 점 유의.
- **paper 측정 잡은 진입을 따로 안 적는다** — 윈도우가 닫혀야 진입+청산을 한 행에
  같이 적는다. 최근 시트가 측정 테이블에 없으면 "윈도우 미도래"부터 의심.
- **운영 DB 시계는 UTC** — 분석 SQL 의 발행일은 `generated_at AT TIME ZONE
  'Asia/Seoul'` 로 맞출 것.
- 컨센서스 수집의 실패 ~95건은 종목 페이지가 없는 ETF/ETN 류로 기존 수집과 같은
  비율. 수집 대상 쿼리가 security_type 필터 없이 시총 상위 300을 자르는 구조인데,
  실패로만 새고 데이터 오염은 없어서 손대지 않았다.
- MS-01 직접 작업: SSH alias `prime-jennie`, DB 컨테이너 `prime-jennie-runtime-postgres-1`
  (pj_admin/prime_jennie_v3), job-worker 컨테이너 `prime-jennie-runtime-job-worker-1`.
